# 0013 - first run: Install WolOS app and Setup Assistant v2
Status: accepted (amends ADR 0004 and ADR 0009)
Context: the live ISO installed from a terminal with text dialogs, and Setup asked seven pages of questions on cards of changing size. The first minutes should ask only what the machine cannot know.
Decision:
- Install WolOS (`wol-installer`, live desktop): one card per step. Choose the disk (model and size from `geom disk list`, only disks `install-disks` allows, at least 16 GB) with an erase warning naming it and the other systems on it (`install-check`: Windows, Linux, macOS, FreeBSD), Erase and Install (checked again first; refused disks say why; Secure Boot on shows a page: WolOS won't start until it is off, Back / Install Anyway / Restart), progress (Pocket Watch, time left from the package rate), WolOS Is Installed + Restart; a stop says where it stopped and offers Try Again (back to the disk) and Restart. The window does not close mid-install, and nothing sleeps it: the app holds the compositor's idle inhibitor for its window and a ScreenSaver inhibit (hypridle: no screen-off, lock or idle sleep on any workspace); `install-run` sets the lid action to NONE and restores it however it exits. Both are given back on done or stop.
- Backend: `sudo -n install-run <disk>` (the live image allows only it and the read-only `install-check` to its user without a password; no terminal; `su` to the empty-password live root where sudo is missing). `install-run` re-checks the disk, lets go of a pool a stopped attempt left under /mnt, then runs the same `/etc/installerconfig` as the boot menu under `script(1)` (distextract wants a terminal) with `WOLOS_INSTALL_DISK` set. The installer script then skips its dialogs, wraps each bsdinstall step (zfsboot: GPT + EFI + BIOS boot + ZFS pool and boot environment; checksum/distextract; bootconfig; config; entropy) to report it first, and replaces bsdinstall's error box with one line plus unmount and pool export, so Try Again starts clean.
- Progress protocol, one line each on stdout: `wolos-install: <stage> <percent> <message>`; stages prepare, disk, files, boot, settings, packages, finish, done, failed. Percent only grows within a run (packages 25-95 from pkg's `[n/m]`); the app creeps the bar during files (no progress of its own) and shows its own sentences, never the message (that is for the log). `shell::install` parses it; tests check every line the scripts print parses.
- Setup steps: Welcome (full-bleed art, Continue), Language & Region (language list + keyboard; guessed from `LANG`, `/var/db/zoneinfo`, `keymap=` in rc.conf; the keyboard applies to the compositor at once), Wi-Fi (skipped when wired; Not Now), Create Your Account, Appearance (Light/Dark/Auto and three looks: Wonderland violet, Ocean blue, Graphite), You're All Set (Get Started). Four questions. Return continues, Escape goes back; Back disappears once the account exists. `shell::setup::Flow` is the state machine; the UI only renders it and runs its jobs off the main thread.
- The account is created on Appearance -> Continue, so Done means it exists; wol-login keeps the session waiting until the assistant fades out (ADR 0012).
- Wire (ADR 0003 framing): `!setup-create-account` = the ADR 0004 fields, avatar tone, accent, then the password (`!setup-create-user` still accepted). `!setup-wifi-scan` -> `ok` + `signal\tsecure\tconnected\tssid` lines (wol-login scans; `_wollogin` cannot reach wpa_supplicant). `!setup-wifi` answers `ok` only once wpa_supplicant joined, `denied` when a secured network refused the password.
- wol-login's account plan adds `~/.local/share/keyrings` (0700, the user's), the theme for the chosen look (`wol-<light|dark|auto>-<accent>`, default accent with Auto = no file) and `/var/db/wolos/avatars/<name>` (one allow-listed tone). Account: administrator (wheel, video, operator), zsh.
- Pages are built from `kit::assistant` only (`tests/kit_only.rs`): fixed-size glass cards over the lock backdrop, the same as the login window and lock screen. Illustrations ship in `/usr/local/share/wolos/illustrations`.
Consequences: the live image carries one sudo rule (`live` may run `install-run` and `install-check` as root). Time left is unknown until the first packages install. Language list is seven locales; more need translations first.
