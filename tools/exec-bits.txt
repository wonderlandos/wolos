# Every file in this tree (with the crates/shell and design submodules) whose first line is a `#!`
# shebang, one repo-relative path per line: each is committed with mode 100755.
# Why: the repos run with core.filemode=false (checked out on Windows), so a plain `git add` records
# a new script as 100644 and a Linux checkout cannot run it (audit5 X6-3: a 0644 sb-key.sh turns the
# Secure Boot layout off without a word). How: add a new script here and commit it with
# `git add --chmod=+x <path>` (an existing one: `git update-index --chmod=+x <path>`);
# crates/controller/tests/exec_bits.rs fails when a shebang file is missing here, a listed file is
# gone or has no shebang, or the git index holds a listed file as 100644.
# Not listed: crates/aurlaws/tests/fixtures/ (scanned as data, never run).
